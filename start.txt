项目目录: D:\LoveFlow_Agent

一、启动本地模型

1. 在 LM Studio 中加载 Negentropy Claude Opus 4.7 9B GGUF 模型。
2. 启动 Local Server，OpenAI 兼容 API 地址应为：

    http://127.0.0.1:1234/v1

当前 LoveFlow 配置文件：

    D:\LoveFlow_Agent\.mimocode\mimocode.jsonc

当前模型上下文配置为 8192 tokens，最大输出为 4096 tokens。此值应与 LM Studio 实际加载的上下文匹配；本机显存不足以稳定加载更大的上下文时，不要仅按 GGUF 的理论上限填写。

二、启动 LoveFlow

在终端中输入：

    loveflow

全局命令会从当前工作区启动 LoveFlow CLI。使用前先确认 LM Studio Local Server 正在运行。

三、常用命令

    loveflow --help       查看帮助
    loveflow --version    查看当前 CLI 版本
    loveflow providers list
                          查看提供商配置
    loveflow models       查看可用模型

四、本地对话与上下文

所有模型请求使用本机 LM Studio 服务。系统提示和自动提醒已从发往模型的对话中移除；附件、工具结果以及压缩后的历史摘要仍会作为任务上下文。历史接近上下文上限时会自动压缩，回答以流式方式显示。

如果 LM Studio 返回 n_keep >= n_ctx 上下文错误，请确认 LM Studio 实际加载的上下文长度与 `.mimocode/mimocode.jsonc` 中的 `limit.context` 一致。
